The stream takes
the direct route.

PearPlay sends a compatible media URL to the receiver. The Apple TV fetches it from the site. The browser extension and local helper carry the controls—not the video.

Your desktop stays on your desktop.

No screen mirroring, no transcode, no Mac acting as a relay for Linux. PearPlay passes the source URL; it does not promise a particular resolution or site compatibility.

Local by design.

No PearPlay account or cloud service required. Pairing credentials stay on your machine. You choose what to send and where it goes.

A deliberate handoff.
Three choices.

One-time setup comes first: load the extension and install the local helper. Then use the popup on the video’s page.

  1. 01 / Access

    Allow, then find.

    Grant website access on a click, start the video, then choose Find videos. This version requires all-sites access for discovery.

  2. 02 / Destination

    Choose the video and TV.

    Connect the helper and find Apple TVs on your network. Select the stream and receiver; pair if asked.

  3. 03 / Send

    Send. Watch. Confirm.

    Press Send to Apple TV. Check for video and sound on the TV before choosing to pause the local video.

Bring your own browser.
Install locally.

Chrome, Python 3.11+, uv, an Apple TV on the same network, and a checkout kept in place. No store package yet. These commands download source and Python dependencies when you choose to run them; this page itself loads offline.

1 / Get the source and isolated helper runtime · Linux or macOS
git clone https://github.com/jcarcinogen/PearPlay.git
cd PearPlay
uv venv --python 3.11 "$HOME/.local/share/pearplay/venv"
uv pip install --python "$HOME/.local/share/pearplay/venv/bin/python" -r requirements.txt

2 / In chrome://extensions, enable Developer mode, load the checkout’s extension/ folder, then copy its extension ID. Set EXTENSION_ID below to that exact value; the installer rejects placeholders.

Linux

The proven playback path. Network discovery can use Avahi when available. A receiver-scoped timing firewall rule may be needed; never disable your firewall.

3 / Register with Chrome
EXTENSION_ID="paste_your_extension_id_here"
PY="$HOME/.local/share/pearplay/venv/bin/python"
"$PY" helper/install.py install \
  --extension-id "$EXTENSION_ID" \
  --browser chrome \
  --config-parent "$HOME/.config" \
  --python "$PY"

macOS · experimental

Installer and discovery adapter only; playback unverified. The helper’s Python needs Local Network access. A successful install does not establish discovery or playback.

Quit Chrome fully after first registration, then reopen it. From the video’s page, open PearPlay and connect the helper. Keep the checkout and Python environment in place. For Local Network caveats, discovery, receiver-scoped timing and ownership-safe uninstall, read the complete install guide.

Before you send.

Useful limits, not small print.

Will it work with every player?

No. The receiver needs a directly fetchable HTTP(S) media URL. A blob: URL cannot be handed off. PearPlay does not transfer browser cookies, bypass DRM or geography, or defeat access controls. Signed and expired URLs may fail. Use only media you are authorized to access.

Can I allow just one website?

The popup offers a per-site grant, but Find videos currently stays disabled without all-sites access. That limitation is disclosed rather than presented as working site-only discovery. Access is requested on a click, not silently at install.

Can I pause the TV from the popup?

No. TV pause/resume are unavailable. End helper session closes the helper connection and does not confirm that the TV stopped. Use the physical remote if playback continues. Local video is paused only after your explicit confirmation of TV video and audio.

Does it block ads?

No. PearPlay respects normal ad delivery and does not bypass DRM, geography or access controls. A pre-roll-to-program transition was observed on the tested FOX path; that does not establish compatibility with every service.

Private control.
No extra account.

The extension communicates with a helper on your machine. Pairing credentials are stored locally in a 0700 directory with a 0600 file. The media origin and Apple TV still communicate over the network; “local” does not make the stream anonymous. No telemetry endpoint is present in the audited extension/helper sources.
