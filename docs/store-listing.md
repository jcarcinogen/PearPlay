# Chrome Web Store listing draft

PearPlay sends a compatible video stream from your browser directly to your Apple TV—without mirroring or re-encoding.

**Requires a separate PearPlay Helper for macOS or Linux.** After installing the extension, a setup tab guides you through connecting the helper. Install the helper once and connect each supported browser you use. No PearPlay account is required.

Current verification: Linux Chrome playback on a tested FOX stream. Native-helper connection checks are separate from TV playback evidence. macOS packaged playback and Brave/Chromium playback remain unverified. Do not submit this draft as a general macOS playback claim before those gates pass.

Only receiver-fetchable HTTP(S) media works. Browser-only URLs, DRM and access restrictions are not bypassed. TV pause/resume are unavailable, and ending a helper session is not a universal TV-stop guarantee. PearPlay does not block ads.

The popup includes an optional tip link to the developer’s X profile. The badge is bundled with the extension; no request to X occurs unless the user opens that link.

Publication prerequisites: permanent extension ID, published matching installers, verified release catalog, project license decision, macOS signing/notarization, browser/distribution testing, store privacy declarations and Scott’s approval. This is a local draft, not a submitted listing.
