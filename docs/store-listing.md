# Chrome Web Store listing draft — 0.3.0 preview

**FLATPAK-INSTALLED VERSIONS OF GOOGLE CHROME AND CHROMIUM ARE NOT SUPPORTED.** On Linux use your distribution’s native browser package format.

PearPlay sends compatible browser video directly to Apple TV—without screen mirroring, re-encoding or a cloud relay. A separate PearPlay Helper is required. No PearPlay account.

Choose a video, find your Apple TV, pair if asked, then Send to TV. Pairing never sends video automatically. Website access is requested when you click; all-sites access is currently required to find videos.

Official Apple TV picture and sound were owner-confirmed on Mac Chrome with a public MP4. Prior playback has been user-confirmed through the extension and helper in Linux Chrome, Brave and Chromium on tested streams. Chrome video and audible sound were separately confirmed. Audio and broader stream compatibility in Brave and Chromium have not been separately documented. Other AirPlay TVs: playback unverified. Windows browser and playback are unverified.

Helper downloads: Mac Apple silicon and Windows x86_64 unsigned previews, plus Ubuntu/Debian x86_64 helper 0.3.0. Fedora 44 and Arch/Omarchy continue using verified helper 0.2.8. Python is bundled. No Intel Mac or Linux/Windows ARM installers. The Mac app is not Apple Developer ID signed or notarized. Keep normal OS protections enabled; use the screenshot installation guide and stop on malware/damage warnings or blocked Windows installation.

The popup offers Send to TV and End helper session, not TV play/pause, seeking, timeline or volume. Use your TV remote. Ending a helper session does not guarantee TV playback stops. Safari extension development is paused.

Only receiver-fetchable HTTP(S) streams work. Browser-only video URLs, cookies, DRM, geography and access restrictions are not bypassed. PearPlay does not block ads. Not every website works.

Mac Chrome and Brave share one helper connection, including disconnection. Linux supports separate Chrome, Brave and Chromium connections. Windows targets the current user’s Chrome. Pairings stay local to that OS user; Windows uses DPAPI. Pair separately on each OS.

No first-party telemetry uploader or cloud media relay. Your browser, dependencies, media provider and TV still communicate over the network. Optional X Money and Ko-fi support links open external services only when clicked; their badge images are bundled locally.
