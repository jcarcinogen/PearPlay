Set up PearPlay

Install the free PearPlay Helper so your browser can connect to Apple TVs on your network. No account. No cloud relay.

1. Install the helper once

  1. Open the Mac installer and follow its instructions.
  2. Open PearPlay Setup in Applications. Select the browsers you want to connect.
  3. Allow local-network access when macOS asks.
  1. Choose the package for your distribution: Ubuntu/Debian, Fedora, or Arch/Omarchy.
  2. Install with your software installer, then open PearPlay Setup from your app launcher.
  3. Select the browsers you want to connect. If your desktop has no graphical package installer, use the developer guide.

One helper serves Chrome, Brave and Chromium for your OS user. Install the PearPlay extension in each browser too. Those browsers have separate website permissions.

Updates, removal and compatibility

The Web Store updates the extension, not the helper. To update the helper, end any casting session, quit your browsers and install the newer package. Pairing information is kept.

To remove it, open PearPlay Setup and disconnect your browsers, then remove the Mac app or Linux package. Saved TV pairing is retained unless you explicitly remove it using the developer guide.

Chrome is the playback baseline. Brave and Chromium require separate verification; sandboxed Flatpak and Snap browsers are not supported by this installer. macOS packaged playback is not yet live-verified.

Only videos the Apple TV can fetch directly work. DRM, restricted streams and browser-only video addresses are not bypassed.
