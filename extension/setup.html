Set up PearPlay

Linux only. Mac support is coming soon.

On Linux, install the free PearPlay Helper so your browser can connect to Apple TVs on your network. No account. No cloud relay.

1. Install the helper once

  1. Choose the package for your distribution: Ubuntu/Debian, Fedora, or Arch/Omarchy.
  2. Install with your software installer, then open PearPlay Setup from your app launcher.
  3. Select the browsers you want to connect. If your desktop has no graphical package installer, use the developer guide.

The Linux package provides browser connections to one helper. Chrome is the verified playback baseline; Brave and Chromium need separate end-to-end verification. Install PearPlay in each browser you use; website permissions are separate.

Development install — Linux Chrome

No public installer is available yet. This preview requires a PearPlay source checkout, Python 3.11+ and uv. This command creates or updates the machine-local helper environment and connects this extension. Review it before running; it downloads Python dependencies.

Use the folder containing helper/install.py and requirements.txt, not its extension subfolder. Mounted shares must be accessible.





After successful installation, fully quit Chrome and reopen it, then click Check connection below. If installation reports preserved or conflicting files, stop and remove the old registration with its original installer; do not overwrite unknown files.

Updates, removal and compatibility
The Web Store updates the extension, not the helper. End casting and quit your browsers before updates. Install the newer Linux package. Saved TV pairing is kept.
Open PearPlay Setup to disconnect browsers, then remove the Linux package. Saved TV pairing is preserved. Changed or unknown files are left alone.
Chrome is the playback baseline. Brave and Chromium require separate verification; sandboxed Flatpak and Snap browsers are not supported by this installer. Mac support is coming soon.
Only videos the Apple TV can fetch directly work. DRM, restricted streams and browser-only video addresses are not bypassed.
