One more step to your TV.

Set up PearPlay

Flatpak-installed versions of Google Chrome and Chromium are not supported. Install Chrome using your Linux distribution’s native package format instead.

Install PearPlay Helper once so your browser can connect to AirPlay TVs on your network. No account. No cloud relay.

PearPlay 0.3.1 preview. Browser video controls work in Chrome on Mac, Windows and Linux. Apple TV picture and sound have owner-confirmed checks on Mac and Windows; Linux has prior playback verification. Other AirPlay TVs vary; LG live HLS remains unresolved.

The downloads below provide helper 0.3.1 for Mac, Windows, Debian/Ubuntu and Arch/Omarchy; Fedora retains the older 0.2.8 helper. Browser timeline and jump controls work before casting; TV seeking and volume are not supported. Pause TV / Resume TV appear only with helper 0.3.1 and a supported authenticated Apple TV session.

1. Install the helper once

  1. Choose your x86_64 package: Ubuntu/Debian (Ubuntu 22.04+ baseline, glibc 2.35+), Fedora 44 (glibc 2.43+) or Arch/Omarchy (glibc 2.35+). ARM packages are not available.
  2. Install with your software installer, then open PearPlay Setup from your app launcher. If Fedora's Software Install reports an authorization failure, open a terminal in your download folder and run sudo dnf install ./pearplay-helper-0.2.8-linux-x86_64.rpm. For Arch / Omarchy, follow the step-by-step instructions below.
  3. Select the browser you use. Fully quit and reopen it. Closing only a tab or reloading the extension is not enough. The package includes Python and the correct extension connection; no extension ID command is needed.
Arch / Omarchy: step-by-step installation

Without a graphical package installer, install the helper using the Terminal app. Do not extract the downloaded file.

  1. Click Download for Arch / Omarchy above and save the file in your Downloads folder, keeping its original filename.
  2. Open the Terminal app. Copy and paste this whole command, then press Enter:
    sudo pacman -U "$HOME/Downloads/pearplay-helper-0.3.1-linux-x86_64.pkg.tar.zst"
  3. If asked, type your computer password and press Enter. Nothing appears while you type your password—that is normal. Review the installation prompt, then type Y and press Enter to continue. Wait until installation finishes.
  4. Open PearPlay Setup from your app launcher and select your browser.
  5. Fully quit and reopen the browser. Return to PearPlay’s Helper setup and click Check connection.

If Terminal says the file cannot be found, check that it is in Downloads and has the filename shown above. If installation fails for another reason, stop and use the installation guide below; do not disable package-signature checks.

The Linux package provides browser connections to one helper. Linux Chrome has prior picture-and-sound confirmation; Brave and Chromium have prior owner-reported playback, not a new candidate test. Install PearPlay in each browser you use; website permissions are separate.

Mac preview · Apple silicon

Download the Mac package above, install it, then open PearPlay Setup and connect your browser. This preview is unsigned and not notarized by Apple. If you deliberately trust it, follow the Mac installation guide with screenshots. It explains Apple’s per-item Open Anyway option and when to stop. Do not disable Gatekeeper or remove quarantine. No Intel Mac package is available.

Chrome and Brave share the Mac native-host registration: connecting or disconnecting it affects both, not just one browser. Chromium has a separate registration. Allow PearPlay to find devices on your local network if macOS asks. Fully quit and reopen the browser. Then check the connection below. A connection check does not establish Mac TV playback.

Windows preview

Download the unsigned Windows preview installer above. It connects the helper to Chrome for your Windows account using a per-user native-host registration. Unsigned builds may be blocked by Windows; do not disable SmartScreen or Defender. A source-only kit is not an installable Windows build.

Saved pairing uses Windows user-local DPAPI protection. It is not portable to another user, computer or operating system; pair on each OS separately. Keep your computer and TV on the same trusted private network. Review any Windows network-access prompt locally; PearPlay does not turn off your firewall. Fully quit and reopen the browser. Then check the connection below. A connection check does not establish Windows TV playback.

Updates, removal and compatibility
The Web Store updates the extension, not the helper. End casting and quit your browsers before updates. Use the installer for your operating system. Saved TV pairing is kept.
Use your platform kit’s documented disconnect and removal flow before removing its app or package. Mac Chrome/Brave disconnection is shared; Windows maintenance uses its supplied per-user installer instructions, not Linux package commands. Saved TV pairing is preserved. Changed or unknown files are left alone.
Linux Chrome has prior picture-and-sound confirmation; Brave and Chromium have prior owner-reported playback. New candidate browser/OS combinations still need separate verification. Sandboxed Flatpak and Snap browsers are not supported by this installer. Mac and Windows builds are unsigned previews. Mac Chrome picture and sound worked on a tested Apple TV stream; Windows Chrome picture, sound, Pause TV / Resume TV and End helper session were owner-tested with a newer helper candidate. Windows setup and maintenance use branded PearPlay windows. The unsigned installer may be blocked by Smart App Control or Application Control, including on the test computer. If blocked, stop and wait for a trusted signed release; do not bypass the block. Other receivers are not generally verified. Safari extension development is paused; this Chrome extension does not expose Safari’s native AirPlay picker. TV timeline, seeking, jump and volume controls are not implemented.
Only videos the Apple TV can fetch directly work. DRM, restricted streams and browser-only video addresses are not bypassed.
